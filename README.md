## Console기반 CRUD 프로그램 작성

***

### 프로그램 요구 사항

- 작가 및 명언에 특수문자 입력 금지
- 명령) 이하에 실행할 명령 입력 [등록, 목록, 삭제, 수정, 종료]

1. 등록
    - json 형식 파일 저장
    - 명언, 작가를 차례로 사용자 입력
    - 인덱스 자동 적용
2. 목록
    - 저장된 명언 목록 내림차순 출력
3. 삭제
    - 삭제?id=k 형태로 입력
    - 삭제된 인덱스는 영구 제명
    - 인덱스 존재 여부 검증
4. 수정
    - 수정?id=k 형태로 입력
    - 명언에 대해 대체 텍스트 입력
    - 인덱스 존재 여부 검증
